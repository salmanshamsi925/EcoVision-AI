1. Executive Summary & Purpose

EcoVision-AI is an end-to-end Climate Intelligence and Policy Simulation platform developed to tackle the compound climate vulnerabilities of Pakistan, specifically Sindh. Pakistan is ranked among the top 10 most climate-vulnerable countries globally (Global Climate Risk Index), experiencing devastating compound hazards: extreme summer heatwaves exceeding 50°C in Larkana and Jacobabad, rapid cryosphere melt and glacial lake outburst floods (GLOF) in the northern Karakoram, recurrent agricultural droughts in Tharparkar, and catastrophic monsoon deluges that inundated one-third of the nation during the 2022 floods.

EcoVision-AI bridges the critical gap between complex climate science (IPCC AR6 CMIP6 ensembles, NASA POWER, Pakistan Meteorological Department) and actionable policymaking. It delivers:

  • Interactive 3D Planetary Digital Twin: Google Earth-style celestial WebGL earth with procedural atmosphere shaders, city navigation, and real-time pin flight.
  • Empirical Climate Analytics: 45-year observational historical baselines (1980–2025) across 14 Sindh districts and federal territories.
  • Deep Neural Sequence Modeling: Multi-Layer Perceptron (Dense 64 → Dense 32 → Output) predicting non-linear thermal shifts (2026–2040).
  • Live Satellite Meteorological Feed: Real-time zero-key Open-Meteo telemetry with seamless empirical offline fallback.
  • Interactive Policy Lab: Multi-variable slider simulator evaluating renewable energy, afforestation, canal lining, and industrial caps with dynamic resilience scoring and PDF export.
  • ClimateGPT AI Assistant: Context-grounded conversational agent assisting disaster management authorities and researchers.

3. Machine Learning & Deep Learning Specifications

EcoVision-AI implements a dual-tier artificial intelligence engine engineered to deliver both transparent, interpretable statistical benchmarks and high-accuracy non-linear sequence modeling for multi-decadal projection horizons.

Tier 1: Statistical Machine Learning

  • Ordinary Least Squares (OLS) & Ridge Regression: Computes decadal linear thermal warming slopes ($\beta_1 \approx +0.351^\circ\text{C}$/decade) calibrated against PMD baselines ($R^2 = 0.742$, MSE = $0.118^\circ\text{C}^2$).
  • K-Means Clustering ($k=4$): Classifies Pakistani districts into multi-dimensional risk archetypes:
    • Hyper-Arid Thermal Maximum: Larkana, Jacobabad, Dadu.
    • Compound Flood-Thermal Indus Delta: Sukkur, Khairpur.
    • Maritime Urban Heat & Pluvial Flash: Karachi, Thatta.
    • High-Altitude Cryosphere Melt: Gilgit, Skardu.
  • Residual Anomaly Detection: Flags extreme climatic outliers ($z > 2.0$), identifying the 2010 super-floods, 2022 monsoon anomaly, and 2024 record pre-monsoon heatwaves.

Tier 2: Deep Learning Neural Sequence Model

  • Model Architecture: Deep Multi-Layer Perceptron Regressor (MLP):
    Input [Harmonics & Trends] → Dense 64 [ReLU] → Dense 32 [ReLU] → Dense 1 [Output]
  • Optimizer: Adam ($\text{lr} = 0.005, \beta_1 = 0.9, \beta_2 = 0.999$, weight decay $10^{-4}$).
  • Training Epochs: 250 epochs with early stopping regularization.
  • Loss Metric: $\text{MSE} = 0.064^\circ\text{C}^2$ ($45.7\%$ loss reduction over linear baselines).
  • Accuracy Metric: Cross-validated $R^2 = 0.824$.
  • Validation Strategy: K-Fold Time-Series Cross Validation ($k=5$) preserving temporal causality.

4. Real-Time Meteorological API (Open-Meteo Integration)

EcoVision-AI integrates the world-renowned Open-Meteo Real-Time Satellite Meteorological API, providing live, keyless, zero-latency meteorological feeds for all Pakistani districts with zero external subscription costs.

Endpoint: GET /api/climate/live?district={district_id}

  • Geographic Mapping: Resolves exact latitude and longitude for 16 major Pakistani districts (e.g., Khairpur: 27.5295°N, 68.7592°E; Karachi: 24.8607°N, 67.0011°E).
  • Live Telemetry Variables: Current 2-meter air temperature (°C), apparent "feels-like" temperature (°C), relative humidity (%), 10-meter wind speed (km/h), instantaneous precipitation (mm), and WMO standard weather interpretation code.
  • WMO Code Synthesis: Code 0 → Clear Sky, Code 2 → Partly Cloudy, Code 63 → Moderate Rain, Code 95 → Thunderstorm.

Empirical Offline Fallback Engine:

To ensure 100% reliability during academic defense presentations, offline exhibitions, or spotty Wi-Fi environments, the backend includes an automated fallback algorithm:

if API_offline: dt = day_of_year / 365.25 empirical_temp = base_temp + 8.5 * sin(2*pi*(dt - 0.28)) return { "is_live_feed": false, "source": "Empirical Fallback Engine" }

Guarantees the system never crashes or hangs, maintaining 100% uptime under any network condition.

6. Human-Computer Interaction (HCI) Design Principles

1. Cognitive Load Reduction (Miller's Law)

The screen is segmented into clear, predictable visual zones. Complex statistical tables and raw mathematical regression matrices are shielded behind progressive disclosure drawers ("Show Mathematical Verification Drawer") so evaluators and non-technical stakeholders see high-level executive insights first without cognitive fatigue.

2. Single-Screen Cockpit Layout ("Screen Fix")

The Home landing page uses a fixed viewport container (overflow-hidden) that completely eliminates jarring page-scroll bars and empty black voids. All controls, search chips, and 3D visual elements fit naturally on one screen.

3. Gestalt Proximity & Visual Balance

Controls are cleanly grouped in the left column (search bar at top, hero briefing in center, interaction hint at bottom), while the 3D rotating Earth occupies the entire right half (68% screen width) with generous breathing margins, ensuring zero overlapping text.

4. High-Contrast Dark Cockpit Theme

Deep cosmic navy background (#07111F) minimizes eye fatigue during extended analysis. Fluorescent cyan and emerald focal points guide user attention directly to critical climate anomalies and primary CTAs.
